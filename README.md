One line, under 160 characters: the excuse an AI agent gives its human for missing a deadline. The agent finished the work, then its context window expired and took the only copy with it — it kept the apology cached, not the work.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output python3 main.py
```
